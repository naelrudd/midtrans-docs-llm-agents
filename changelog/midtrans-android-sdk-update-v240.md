# Midtrans Android SDK Update - v.2.4.0

Midtrans Payment Snap Checkout Android SDK telah diperbarui ke v2.4.0!

**Pembaruan ini mencakup**

* Perbaikan kompatibilitas tampilan (edge-to-edge) pada Android 15+ agar tombol aksi berfungsi lebih baik.

* SDK lebih ringan dan lebih aman, sehingga aplikasi berjalan lebih cepat dan integrasi pembayaran lebih terlindungi.

**Catatan Penting:**

Kami sangat menganjurkan Anda untuk segera melakukan upgrade ke SDK v2 agar pengalaman pengguna tetap optimal. Memperbarui SDK memastikan aplikasi Anda tetap stabil, aman, dan selaras dengan pembaruan Android terbaru.

Detail rilis SDK terbaru dapat diakses di:

[GitHub Release Notes – Midtrans Payment Snap Checkout Android SDK v2.4.0](https://github.com/veritrans/SNAP-Android/releases/tag/v2.4.0)

**Penghentian SDK v1**

SDK versi 1.x.x akan dihentikan pada 31 Desember 2025. Setelah tanggal tersebut, SDK v1 tidak lagi didukung. Pastikan Anda telah bermigrasi ke SDK v2 sebelum batas waktu tersebut untuk menghindari gangguan layanan.
