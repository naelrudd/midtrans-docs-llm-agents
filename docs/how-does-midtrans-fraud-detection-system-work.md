# How does Midtrans’ fraud detection system work?

Midtrans’ proprietary fraud detection system, **FRS (Fraud Rules Service)**, provides a set of tools to help identify and prevent fraudulent transaction. The first mechanism is through a blacklist database we have. The second mechanism is through a rules-based engine that checks transaction patterns based on numerous data points such as card number, email, phone number, and many more. The third mechanism is through machine learning where a transaction will be given a score based on its risk level.
