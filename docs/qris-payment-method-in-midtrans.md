# QRIS Payment Method in Midtrans

By activating QRIS payment method in Midtrans, merchants will be able to accept cashless payments via dynamic QRIS code. Customers will be able to choose to pay via QRIS when doing payments via desktop.

> 🚧 Note 💡
>
> Existing merchants that already accept GoPay, can automatically accept QRIS. You may visit [this link ↗](https://demo.midtrans.com/) for the demo.
