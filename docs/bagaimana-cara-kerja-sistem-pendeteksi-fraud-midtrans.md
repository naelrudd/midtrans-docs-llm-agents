# Bagaimana cara kerja sistem pendeteksi fraud Midtrans?

Sistem pendeteksi *fraud* Midtrans, ***FRS (Fraud Rules Service*)**, memiliki berbagai metode untuk mengidentifikasi dan menghindari transaksi *fraud*. Metode pertama adalah melalui pencocokan dengan database *blacklist* yang *FRS* miliki. Metode kedua adalah dengan menggunakan *rules-based engine*; dimana *FRS* melakukan analisa terhadap pola perilaku transaksi melalui berbagai data seperti nomor kartu, email, nomor telepon, dan lain sebagainya. Metode selanjutnya adalah menggunakan machine learning dimana FRS akan memberikan nilai/skor berdasarkan resikonya.
