# Introduction to Payment Link

Payment Link menyediakan cara mudah untuk menerima pembayaran dari pelanggan Anda. Midtrans membuat link yang mengarahkan pelanggan ke halaman pembayaran Midtrans. Anda dapat membagikan Payment Link melalui saluran apa pun seperti email, WhatsApp, dan sebagainya. Mudah digunakan dan **tidak diperlukan integrasi teknis**.

Payment Link cocok untuk penjual atau pemilik usaha kecil di platform media sosial seperti Instagram, Facebook, dan sebagainya. Juga, sangat cocok untuk mereka yang memiliki event & webinar musiman atau satu kali dan tidak memiliki situs web.

Anda dapat melihat panduan lengkap pada [link berikut ↗.](https://docs.midtrans.com/en/payment-link/overview)
