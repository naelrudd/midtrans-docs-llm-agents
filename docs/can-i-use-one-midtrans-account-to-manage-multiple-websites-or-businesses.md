# Can I use one Midtrans account to manage multiple websites or businesses?

According to Payment Provider regulations, the use of Midtrans credentials/accounts on more than one website is allowed, provided that the websites are still in the same domain & scope of business.

For example:

* example.com/
* event.example.com/

If the desired domain is different, please make sure that the related website address is still in the same business scope. You can contact us by filling out and submitting [this form ↗](https://midtrans.com/contact-us/registration-and-service-information/pertanyaan-lain) to confirm more about this matter.
