# What is fraud?

Fraud in payments normally refers to a transaction that is unauthorized/illegal. For example, a fraudulent card transaction is a card transaction that is not authorized by the legitimate cardholder. The fraudsters typically illegally obtained the card information and then use it to purchase goods/services for his/her own benefit.
