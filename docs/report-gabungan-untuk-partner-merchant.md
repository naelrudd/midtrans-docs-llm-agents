# Report Gabungan untuk Partner Merchant

**Unified Reporting** adalah Report Gabungan yang dapat memudahkan Partner merchant melihat dan memfilter transaksi pembayaran tanpa login ke spesifik merchant melalui Dashboard Merchant, dengan cara:

1. Login ke [Dashboard Partner Portal](https://dashboard.midtrans.com/partner/login)

   <Image align="center" src="https://files.readme.io/1faeea3-Picture1.png" />
2. Pilih menu Transaksi, dan pilih History

   <Image align="center" src="https://files.readme.io/e63e826-Picture2.png" />
3. Pada menu Transaction History, Anda dapat menyesuaikan tipe transaksi yang akan ditampilkan pada halaman ini dan menggunakan kolom **search** untuk mencari berdasarkan spesifik Merchant ID

   <Image align="center" src="https://files.readme.io/419294f-Picture3.png" />
