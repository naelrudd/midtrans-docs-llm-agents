# Kendala login karena kode 2FA (Two-factor Authentication), apa yang harus saya lakukan?

Jika Anda tidak dapat login karena *two-factor authentication*, itu berarti fitur keamanan tambahan ini telah diaktifkan melalui *dashboard* Midtrans, sehingga **login hanya dapat dilakukan menggunakan kode unik yang diberikan oleh aplikasi Google Authenticator.**

![](https://files.readme.io/91c8779-image.png)

Jika Anda ingin menonaktifkan fitur keamanan tambahan ini. Silakan hubungi *support* agent kami melalui halaman [Contact Us ↗](https://midtrans.com/id/kontak-kami/aktivasi-merchant/saya-lupa-kode-two-factor-authentication-untuk-login-midtrans), isi dan submit formulirnya.

> 🚧 Catatan 📝
>
> Fitur keamanan tambahan ini bersifat **opsional** untuk diaktifkan.
