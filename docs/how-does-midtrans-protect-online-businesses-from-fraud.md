# How does Midtrans protect online businesses from fraud?

Midtrans provides a set of tools through **FRS (Fraud Rules Service)**, Midtrans’ proprietary fraud detection system.

**FRS** helps our partners to catch and detect fraudulent transactions, while keeping false positives at a minimum and maximizing acceptance rate.
