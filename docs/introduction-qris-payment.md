# Introduction QRIS Payment

**QRIS (Quick Response Indonesian Standard) code** is a standardized QR code as regulated by Bank Indonesia (BI) and Asosiasi Sistem Pembayaran Indonesia (ASPI) to facilitate cashless payment in Indonesia.

QRIS was first launched by BI on August, 17th 2019 and available in Midtrans as a payment method from January, 1st 2020. With QRIS, customers can pay by scanning the QR code using any supporting QRIS payment app (from e-Wallet apps such as GoPay, OVO, Dana, LinkAja, to mobile banking applications that have a QR scanner feature such as BCA, Sinarmas, Maybank, CIMB, etc.)

By activating the QRIS payment method in Midtrans, merchants will be able to accept cashless payments via dynamic QRIS code. Customers will be able to choose to pay via QRIS when doing payments via desktop.

# The benefit of using QRIS

1. For Merchant\
   Easily accept cashless payments from popular payment apps with just 1 QR-based payment method.\
   Merchants will only need to register once to accept payments from any QRIS-supporting payment apps.
2. For Customer\
   Gives customers a wide choice of payment options.\
   Customers do not need to install multiple payment apps in order to pay.

# Signing up for QRIS

Simply register via [Midtrans Website ↗](https://midtrans.com/tentang-passport) and complete the onboarding process.\
Existing Midtrans merchants that already accept GoPay can automatically accept QRIS.
