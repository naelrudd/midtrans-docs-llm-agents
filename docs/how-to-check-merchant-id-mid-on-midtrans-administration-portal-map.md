# How to check Merchant ID (MID) on Midtrans Administration Portal (MAP)

Merchant ID (MID) is a unique identity owned by every merchant registered in Midtrans. MID is used to differentiate between one merchant and another. You can find the MID through the Merchant Administration Portal (MAP) by following these steps:

1. Log in to the Merchant Administration Portal (MAP) using your email and password.

   <Image align="center" src="https://files.readme.io/149721b-ed740409-40c5-483a-b544-e6d6bd143245.png" />
2. Select “**Settings**” and then click “**Access Keys**”, Merchant ID (MID) will start with **G, M, or A** and continue with a random number.

   <Image align="center" src="https://files.readme.io/29769ab-467ecc4d-216e-4736-85ad-7143ed6ad0e5.png" />
3. Alternatively, you can find the Merchant ID (MID) on your “**Profile**” menu:

   1. Click “**Profile**” on the top right side (Number 1)
   2. Merchant ID (MID) will be shown under Merchant Name (Number 2)

   <Image align="center" src="https://files.readme.io/9a73042-Untitled_design_5.png" />
