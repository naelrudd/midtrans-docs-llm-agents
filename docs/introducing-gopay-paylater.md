# Introducing GoPay PayLater

**GoPay PayLater** is a new payment method from GoJek, where you can order various GoJek services at any time and pay only once at the end of the month. This feature is the result of GoJek's collaboration with Findaya, which is registered and supervised by OJK. It's easy to use, just select GoPay PayLater as your payment option on the checkout page.

See complete information about [GoPay PayLater ↗](https://gopay.co.id/blog/gopaylater).
