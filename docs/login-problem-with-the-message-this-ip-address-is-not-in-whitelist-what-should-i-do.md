# Login problem with the message "This IP address is not in whitelist", what should I do?

If you are unable to login due to "**IP address is not in whitelist**", that means this feature has been activated via Midtrans dashboard, which makes **login can only be done using a device with a registered IP address.**

![](https://files.readme.io/457cf75-image.png)

If you want to disable this feature, please contact our team via [Contact Us ↗](https://midtrans.com/contact-us/aktivasi-merchant/muncul-notifikasi-this-ip-is-not-in-whitelist-ketika-saya-login) page and fill in the form.

> 🚧 Note 📝
>
> This additional security feature is **optional** to be activated.
>
> You can manage this feature via Midtrans Dashboard. Please [click here ↗](https://docs.midtrans.com/docs/midtrans-dashboard-usage#ip-whitelisting) for the details.
