# Bagaimana cara saya mulai menggunakan Midtrans untuk menerima pembayaran?

Agar dapat menerima pembayaran dari konsumen bisnis Anda melalui Midtrans, silakan ikuti langkah-langkah berikut:

Setelah akun Anda sudah dibuat:

1. [Login ↗](https://dashboard.midtrans.com/login) ke dashboard Anda, atau lakukan [registrasi ↗](https://dashboard.midtrans.com/register) jika belum memiliki akun Midtrans.\
   Pastikan Email Bisnis dan Nomor Telepon Bisnis belum pernah terdaftar di merchant Midtrans/GoBiz/GoFood.
2. Klik tombol **“di sini”** pada banner jingga yang ada di *dashboard* Anda.

   ![](https://files.readme.io/4bec0ba-image.png)
3. Silakan ikuti petunjuk pengisian data bisnis, unggah dokumen yang dibutuhkan, setujui syarat dan ketentuan yang berlaku, lalu klik **“Ajukan”**.
4. Setelah itu, Anda akan dialihkan ke *dashboard* Midtrans mode ***Production***. Anda sudah dapat langsung menggunakan layanan Transfer Bank (Permatabank VA, BNI VA, BRI VA, & Mandiri Bill), GoPay, dan QRIS.

> 🚧 Catatan
>
> Jika anda ingin mengaktivasi metode pembayaran selain Transfer Bank (Permata VA, BNI VA, BRI VA, & Mandiri Bill), Card Payment, QRIS dan GoPay, silakan login ke dashboard lalu pilih **“+ METODE PEMBAYARAN”.**
>
> Jika anda ingin menggunakan metode integrasi Core API, silakan mengakses [link ini ↗ ](https://support.midtrans.com/hc/id/articles/4413105914137-Apa-itu-Core-API-Bagaimana-cara-mengintegrasikannya-dengan-tampilan-bisnis-saya-)untuk informasi lebih lanjut.
