# Apakah saya harus memiliki situs web untuk aktivasi akun Midtrans?

Anda tetap bisa melakukan pengajuan aktivasi dengan menggunakan tautan yang mewakili bisnis Anda, seperti akun sosial media (Facebook, Instagram) bisnis Anda, atau dengan melampirkan katalog produk.

Berikut contoh situs *non-web* atau aplikasi yang dapat kami terima dan proses untuk aktivasi akun:

* Media Sosial: <https://www.instagram.com/padmala.atelier/>
* *Marketplace*: <https://www.tokopedia.com/kertasive>

Jika Anda mendaftarkan usaha menggunakan katalog produk, bisnis Anda hanya dapat menerima pembayaran melalui Transfer Bank yaitu Permata Bank Virtual Account (VA), BNI VA, BRI VA, Mandiri Bill, QRIS, dan GoPay saja.
