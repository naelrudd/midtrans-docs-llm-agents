# Mengapa pengajuan aktivasi saya ditolak?

Penolakan terhadap pengajuan aktivasi Anda dapat ditolak karena berbagai alasan, diantaranya karena  dokumen tidak valid/sesuai ketentuan, situs web tidak dapat diakses, barang yang dijual termasuk dalam kategori yang tidak diperbolehkan, dsb.

Silakan melihat informasi terkait kriteria yang harus diperhatikan untuk mengaktivasi akun Anda:

* Kriteria [legalitas dokumen individu ↗](https://drive.google.com/file/d/1Ny-hQI-VV-jZ9a0DSSiv5N9TYB39ai5x/view)
* Kriteria [legalitas dokumen badan usaha ↗](https://drive.google.com/file/d/1VwJhScv4rsMJoSvrx9CNetki147psknu/view)
* Kriteria [situs web ↗](https://support.midtrans.com/hc/id/articles/4413106450201)
* Kriteria [barang dan jasa yang dilarang ↗](https://support.midtrans.com/hc/id/articles/204403474)
