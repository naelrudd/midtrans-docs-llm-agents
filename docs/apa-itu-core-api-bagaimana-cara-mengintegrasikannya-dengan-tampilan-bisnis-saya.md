# Apa itu Core API? Bagaimana cara mengintegrasikannya dengan tampilan bisnis saya?

Midtrans Core API adalah layanan yang memungkinkan Anda untuk merancang & menyesuaikan tampilan pembayaran pada situs/aplikasi sesuai dengan kebutuhan bisnis Anda. Dengan menggunakan layanan ini, Anda dapat dengan mudah mengintegrasikan layanan Midtrans ke sistem Anda (web, aplikasi, PoS, IoT, dsb.)

Jika Anda tidak/belum ingin mengintegrasikan Midtrans Core API dengan sistem Anda, maka layanan default yang akan digunakan adalah [SNAP ↗](https://docs.midtrans.com/en/snap/overview) ー dengan tampilan yang mengikuti standar Midtrans.

Info lebih lanjut dapat Anda simak langsung pada halaman [Core API Midtrans ↗](https://docs.midtrans.com/en/core-api/overview).

Untuk pengajuan aktivasi layanan CoreAPI, silahkan akses [Hubungi Kami ↗](https://midtrans.com/id/contact-us/payment-method-and-service-addition-1/bagaimana-cara-mengaktifkan-layanan-core-api), isi dan submit form yang tersedia.
