# Apa arti dari error 402 dengan pesan “Merchant doesn’t have access for this payment type”?

Silahkan mengakses halaman [contact us ↗](https://midtrans.com/id/kontak-kami/technical-integration-development/i-get-error-code-402-when-doing-integration) kami untuk proses aktivasinya, isi dan *submit form* nya.
