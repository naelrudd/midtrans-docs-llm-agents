# What’s the difference between Server Key and Client Key? How do I access them?

Both keys, collectively known as Access Keys, are vital identification components of your Midtrans account. You need to put these keys on your config file. The client key is used to generate credit card tokens specifically for Core API implementation, while the server key is used for the remainder of API calls on the server side.

You can see your access keys in your Merchant Administration Portal (MAP) at [Settings > Access Keys](https://dashboard.midtrans.com/settings/config_info).
