# Unified Report for Partner Merchant

**Unified Reporting** is a Unified Report that can make it easier for merchant Partners to view and filter Payment transaction transactions without logging in to a specific merchant via the Merchant Dashboard, with this step:

1. Login to [Dashboard Partner Portal](https://dashboard.midtrans.com/partner/login)

   <Image align="center" src="https://files.readme.io/243e6be-Picture1.png" />
2. Select Transaction menu, and choose History

   <Image align="center" src="https://files.readme.io/1605f74-Picture2.png" />
3. In Transaction History menu, you can customize it by the types of transactions, and use the **search** field by input the specific MID

   <Image align="center" src="https://files.readme.io/d2e29b6-Picture3.png" />
