# Kendala login dengan pesan "This IP address is not in whitelist", apa yang harus saya lakukan?

Jika Anda tidak dapat login karena *"IP address is not in whitelist"*, itu berarti fitur keamanan tambahan ini telah diaktifkan melalui dashboard Midtrans, yang membuat **login hanya dapat dilakukan menggunakan perangkat dengan alamat*IP* yang terdaftar.**

![](https://files.readme.io/1a19975-image.png)

Jika Anda ingin menonaktifkan fitur keamanan tambahan ini. Silakan hubungi support agent kami melalui halaman [Contact Us ↗](https://midtrans.com/id/kontak-kami/aktivasi-merchant/muncul-notifikasi-this-ip-is-not-in-whitelist-ketika-saya-login), isi dan submit formulirnya.

> 🚧 Catatan 📝
>
> Fitur keamanan tambahan ini bersifat opsional untuk diaktifkan.\
> Anda dapat mengatur fitur keamanan tambahan ini melalui Dashboard Midtrans. Silakan [klik di sini ↗ ](https://docs.midtrans.com/docs/midtrans-dashboard-usage#ip-whitelisting) untuk detailnya.
