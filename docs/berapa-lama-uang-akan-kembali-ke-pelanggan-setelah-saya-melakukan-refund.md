# Berapa lama uang akan kembali ke pelanggan setelah saya melakukan refund?

Biasanya uang akan kembali ke pelanggan pada 7-14 hari kerja setelah proses *refund* telah dilakukan.\
Sedangkan untuk transaksi *cross border* (kartu kredit/debit internasional), biasanya pengembalian uang akan sedikit lebih lama (hingga 45 hari).
