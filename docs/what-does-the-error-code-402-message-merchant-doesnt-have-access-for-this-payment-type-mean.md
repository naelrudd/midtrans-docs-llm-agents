# What does the error code 402 message “Merchant doesn’t have access for this payment type” mean?

This error message appears if you are trying to use any payment channel that is not activated yet. If you want to activate any specific payment method, please reach us via our [Contact Us page ↗](https://midtrans.com/contact-us/technical-integration-development/i-get-error-code-402-when-doing-integration) and fill the form.
