# Bagaimana cara Saya melakukan modifikasi terhadap tampilan metode pembayaran di aplikasi Saya ?

Anda bisa melakukan modifikasi terhadap tampilan metode pembayaran yang diinginkan melalui portal Midtrans yang Anda miliki.

Silahkan login ke portal Midtrans Anda, akses ke menu [Pengaturan > Snap Preferences ↗](https://dashboard.midtrans.com/settings/snap_preference?language=id), silakan pilih *tab* ***Payment Channels***.
