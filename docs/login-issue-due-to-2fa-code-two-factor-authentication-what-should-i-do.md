# Login issue due to 2FA code (Two-factor Authentication), what should I do?

If you are unable to login due to Two-factor Authentication, that means this feature has been activated via Midtrans dashboard, which will **require you to login by entering the unique code found in the Google Authenticator app.**

![](https://files.readme.io/487036d-image.png)

If you want to disable this feature, please contact our team via [Contact Us ↗](https://midtrans.com/contact-us/aktivasi-merchant/saya-lupa-kode-two-factor-authentication-untuk-login-midtrans) page and fill in the form.

> 🚧 Note 📝
>
> This additional security feature is **optional** to be activated.
