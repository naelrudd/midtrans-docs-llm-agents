# How to login to the Merchant Administration Portal - Partner / Multi-outlet for the first time?

For an **existing master portal user**, you can use the same email address you used before. Here are the steps that Merchants need to follow to **trigger the migration (only for the first time).**

> 🚧 Note 📝
>
> If your email address is being used to login for partner and merchant, then the **same password will apply for both.** You don't have to reset the password.

1. Click on [this link ↗.](https://dashboard.midtrans.com/login?language=en)
2. Select Partner and click Forgot password?

   ![](https://files.readme.io/c19e727-image.png)
3. Type your registered email.

   ![](https://files.readme.io/18c09d1-image.png)
4. Click Send link.
5. You’ll get a reset password email to create a new password. Email should be received within five minutes.

   ![](https://files.readme.io/708b39b-image.png)
6. Check your email with this subject "Reset Password", and then click "Change my password".

   ![](https://files.readme.io/b983b8a-image.png)
7. Enter your new password and then re-enter your new password.

   ![](https://files.readme.io/d008859-image.png)
8. Click "**Reset now**".
9. You will be redirected to the [Login ↗](https://dashboard.midtrans.com/login?language=en) page upon clicking Reset now.
10. Select **Partner**, input your **registered email** into the email address field, your **new password** into the password field, and then click "**Log in**".

    ![](https://files.readme.io/ef85cc0-image.png)
11. The migration process has been completed and ready to use.

If you still encounter an error or difficulties during migration or login to your new dashboard, please contact our support team through [this link ↗](https://midtrans.com/contact-us/irispayouts-service-information/other-question-1).

## Merchant Management

If your role is an **Admin**, you have a function to edit **roles & assigned merchants**. Here, you can change which role is assigned to a merchant.

1. Click Manage User.

   ![](https://files.readme.io/bfe0b0d-image.png)
2. Type **User name** and click **Apply** or simply select from the list.
3. Click **Edit**.
4. Click on the **dropdown list**.

   ![](https://files.readme.io/e412046-image.png)
5. Type the **merchant name** or simply select from the list.

   ![](https://files.readme.io/cca49ec-image.png)
6. Click on the **checkbox** to assigned or unassigned merchant.
7. Click **Submit**.

> 🚧 Note 📝
>
> If a user is not assigned to one (or more) merchants, then that user will not be able to see the merchant in the Dashboard, even if the role is Admin.
>
> For example, there is user X and merchants A, B, and C. Then, user X is assigned to merchants A and C but is not assigned to merchant B, so merchant X can only be able to see merchants A and C but will not be able to see merchant B.

## Edit Profile

You can click on the edit profile on the top right of your dashboard. Here, you can **change the name** and **password**.

1. Click on the **dropdown list**, choose the role.

2. Type the merchant name.

## User Management

In Manage User, you can see the list of users of your partner. Here you can see the **user name, account status, email,** and **their role (only Admin can access this page).**

![](https://files.readme.io/209c9b7-image.png)

### A. You can search users based on their name.

1. Select **User list**.

   ![](https://files.readme.io/5403742-image.png)
2. Type the user name.
3. Click Apply.

<br/>

### B. You can search users based on their roles.

1. Select **User list.**

   ![](https://files.readme.io/e60065d-image.png)
2. Click on the **dropdown list**, choose the **role**.
3. Click **Apply**.

<br/>

### C. You can create new users.

1. Select **User list**.

   ![](https://files.readme.io/f6f20cb-image.png)
2. Click **+ Add user**.
3. Type the **user name.**

   ![](https://files.readme.io/b6d4bb6-image.png)
4. Type the **user email**.
5. Click on the **dropdown list**, choose the **role**. You can choose **multiple roles** for a user.
6. Type the **merchant name** that this user can access, or simply **select the merchant** from the list.

   ![](https://files.readme.io/e644a11-image.png)
7. Click **Submit.**
8. The user account status will be “**Not confirmed**”.

   ![](https://files.readme.io/879893f-image.png)

The user **needs to confirm the link sent to their email** to confirm the account and set up the password. Once done, the user account status will be “**Active**”.

<br/>

### D. You can also edit the existing users. You can edit the **user name, roles,** or **the assigned merchants** by clicking on the “**Edit**” button.

![](https://files.readme.io/e0b529a-image.png)

<br/>

### E. If you need to delete users, you can use the “Delete” button on the respective user in this page.

> ❗️ Important ❗
>
> Please note that you can’t undo the deletion, so be mindful before deleting users since they will lose access to the dashboard.

![](https://files.readme.io/ad92fc0-image.png)
