# Saya mendapatkan pesan error "failed to register transaction", apa yang harus Saya lakukan ?

Ada beberapa kemungkinan yang bisa Anda cek terkait hal tersebut :

1. Mohon pastikan Anda sudah menggunakan SDK yang paling baru, Anda bisa mendapatkan SDK terbaru pada github kami [di sini ↗](https://github.com/veritrans/veritrans-android/releases).
2. Kesalahan dalam melakukan implementasi merchant server, Anda bisa mendapatkan penjelasan lebih lanjut terkait hal ini dalam dokumentasi teknis kami [di sini ↗.](https://mobile-docs.midtrans.com/#prerequisites)
3. Masalah koneksi jaringan. Jika masalah masih terjadi, silahkan berikan informasi dari respon log SDK Anda, dengan mengirimkan detail-nya ke [form berikut ↗.](https://midtrans.com/id/contact-us/technical-integration-development/other-question)

> 🚧 CATATAN
>
> masalah ini terjadi hanya jika Anda melakukan integrasi dengan menggunakan Android.
