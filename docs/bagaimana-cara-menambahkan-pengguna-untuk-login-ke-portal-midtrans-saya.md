# Bagaimana cara menambahkan pengguna untuk login ke portal Midtrans Saya?

Pada *Merchant Administration Portal* (MAP), lakukan langkah-langkah berikut:

1. Buka menu **Akun > Kelola Pengguna**, pada kolom Buat Akun Baru, isikan Nama dan Alamat Email kemudian centang *Activate Account*.

2. Pilih *Role User*, kemudian klik ***Create User***.

3. Aktivasi *email* tersebut dengan klik *link* yang terkirim ke email.

> 🚧 Catatan 📝
>
> Proses tersebut hanya dapat dilakukan oleh user dengan *role Admin*.

Setelah klik link yang terkirim ke *email*, *user* akan diarahkan ke halaman pengisian data. Silahkan isi bagian ***Telephone, Password dan Password Confirmation*** kemudian klik ***Sign Up***.

Akun baru telah berhasil ditambahkan dan dapat digunakan untuk login.

> 🚧 Notes 📝
>
> Silahkan pastikan nomor telepon yang diisi belum terdaftar di Midtrans untuk akun lain.
