# Access Keys

# Overview

***

<br />

The Access Key page provides essential API credentials required to integrate Midtrans payment gateway with your website or application. These keys establish secure communication between your systems and the Midtrans payment infrastructure.

<br />

# API Keys

***

<br />

This section displays your unique authentication credentials.

* Merchant ID:  Your unique identifier in the Midtrans system. Use this Merchant ID when communicating with Midtrans's Support or Sales.
* Client Key: Used for client-side integration.
* Server Key: Used for secure server-side API calls and transaction verification.

> 📘 Important notes about Client Key and Server Key
>
> * You will need to include both Client Key and Server Key in any of your API call's headers when interacting with Midtrans's services.
> * These keys are automatically generated and cannot be modified
> * If you need to change your keys, contact the Midtrans Support Team
> * Keep your Server Key confidential as it provides access to sensitive transaction operations
