# Apakah proses integrasi SDK Midtrans bisa menggunakan Cordova ?

Saat ini Midtrans belum mendukung untuk integrasi menggunakan Cordova. Kami masih fokus dalam melakukan integrasi dengan *framework native*. Informasi akan diberikan jika Midtrans sudah bisa melakukan integrasi dengan *framework hybrid*.
