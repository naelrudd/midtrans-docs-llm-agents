# Is it possible to login simultaneously using the same account?

You can use the same account to [log in ↗](https://dashboard.midtrans.com/login?language=en) to the Merchant Administration Portal (MAP) at once. However, **simultaneous logins are limited to three persons**.

If there is a fourth person who wants to log in, then that person must wait for one of the three people to log out first, and then wait for 15 minutes. After that, the fourth person can log in.

In addition, if you do the login-logout process more than three times within 15 minutes, then this is not possible. You can log in again after 15 minutes.
