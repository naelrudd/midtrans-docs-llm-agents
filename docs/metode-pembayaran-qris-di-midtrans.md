# Metode Pembayaran QRIS di Midtrans

Dengan mengaktifkan metode pembayaran QRIS di Midtrans, merchant dapat menerima pembayaran non tunai melalui kode QRIS dinamis. Pelanggan dapat memilih untuk membayar melalui QRIS ketika melakukan pembayaran melalui desktop.

> 🚧 Catatan 📝
>
> Merchant Midtrans yang dapat menggunakan GoPay, **secara otomatis dapat menggunakan QRIS**. Anda dapat mengunjungi [link berikut ↗](https://demo.midtrans.com/) untuk demo.
