# What is 3D-Secure?

Three Domain Secure (3D-Secure or 3DS) is a security protocol supplementing online transactions made using cards by authenticating cardholders with one time password (OTP).

While processing transactions secured by 3DS, cardholders will be redirected onto their respective Issuing Banks’ page to input OTP sent via SMS, USSD, or email. This service may otherwise be recognized as **Verified by Visa** (for Visa cards), **MasterCard SecureCode** (for MasterCard cards), **J/Secure** (for JCB cards), or **Safekey** (for American Express cards).

Keep in mind that cardholders remain able to complete transactions if their cards aren’t yet to be enrolled in 3DS. There will be no OTP authentication involved as well as security benefits that come with it.
