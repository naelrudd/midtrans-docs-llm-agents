# Setting up Notification URL

You can only start setting up Notification URL if you have done the Credential Exchange step, otherwise the button will be disabled. Do this for both Sandbox and Production.

<br />

<Image alt="Setting up BI SNAP Notification URL" align="center" src="https://files.readme.io/33dae498d3bcb0004e0c898197f01fcf2a9eac2e79ed8035c8a1a4cb6501eef1-notif_URL.png">
  Setting up BI SNAP Notification URL
</Image>

<br />

1. Go to Settings > Payments > BI Snap Notification URL
2. Fill in your Notification URL endpoint at the 'Set notification URL' section, then click Save.
3. Afterwards, the Midtrans Public Key will be generated.
