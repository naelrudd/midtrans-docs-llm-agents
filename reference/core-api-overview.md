# Overview

This section provides merchants with API references for Core API, Midtrans's Payment API that can be integrated to your own checkout interface.

Step by step integration walkthrough is available [here](/docs/custom-interface-core-api).

If you don't want to build everything from scratch and use a prebuilt hosted checkout page, consider integrating to [Snap](reference/snap-api-overview) instead.
