# Testing MiniApp V2

This guide explains how to test your miniapp live using the MiniApp Deeplink provided in the integration guide.

After submitting your Create New MiniApp request, you can test your miniapp using the MiniApp Deeplink provided in the integration guide shared via email.

## MiniApp Deeplink

* Location: Find the deeplink in the MiniApp Integration Guide sent to your email.
* Purpose: Use this link to test your miniapp live in GoPay.

***

## How to Open MiniApp

### iOS:

1. Copy the deeplink.
2. Open Safari and paste the link in the address bar.
3. Hit “Go” to launch the miniapp.

### Android:

1. Download and install the Deeplink Tester from the Play Store.
2. Open Deeplink Tester.
3. Paste your miniapp deeplink and run it to test your miniapp live.
