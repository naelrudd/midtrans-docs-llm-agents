# Register IP Address

<Image alt="Registering IP Address for BI SNAP" align="center" src="https://files.readme.io/5be4672643cd735d4e0b98568caf6726aa1de577dbd52d064dfe7e865d52794a-IP_Register.png">
  Registering IP Address for BI SNAP
</Image>

<br />

You'll need to whitelist your IP as part of the required steps. You can only do it for Production environment.

1. Go to Settings > Access Key > Payment BI Snap section, then click Register IP Address.
2. Input your IP Address, then click Submit. It might take up to 3 working days to whitelist your IP Address.
3. You can check back the status of your whitelist in this page. If it's done, the status will be changed from `In progress` to `Registered`.
4. You can whitelist multiple IP addresses. To do so, click the Add more button when listing down the IP Address.
